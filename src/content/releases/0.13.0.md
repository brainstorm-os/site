Most products bolt an assistant onto the side. A box in the corner that answers
questions, with no standing in the thing it is helping you with.

Brainstorm takes the other route. An agent here is a member of your vault. It has
a name and a face, it shows up in **Settings → Team** next to the people, and it
holds permissions from the same list a person holds — not a separate, vaguer set
that means "AI stuff". You grant them, you see them, you take them away.

Everything follows from that. You mention it in a channel by typing `@` and its
name, and it answers in the thread with the vault as context. You can put one on
an automation as the assignee, and it does the work when the automation fires. One
agent can hand work to another, and the second runs with the permissions both of
them have — never more.

It proposes, you approve. An agent does not write to your vault behind your back;
changes arrive as cards you read first. And **Settings → AI** now has an Agent
activity panel showing every run, every tool call, and every refusal, filterable,
because "it did something" is not an answer.

## Apps talk to each other now

Until now each app was an island. Files knew about files. Tasks knew about tasks.
If you wanted something from one while working in another, you went there yourself.

An app can now publish typed actions that other apps discover and call. The
practical effect is that an action defined by one app turns up where you actually
are: in any object's `⋯` menu, in the editor's `/` menu and block menu, as a step
in an automation, and as something your agent can call on your behalf.

You are asked before the first one runs, and asked again if the app later changes
what that action does. An app cannot quietly acquire a new reach into your vault
by editing its own description.

## Two new themes

**Porcelain** is a flat paper-white light theme — no gradients, no glass. **Graphite**
is its charcoal dark twin. Both sit alongside the existing set in
**Settings → Appearance**.

## A pass over every app

Twenty apps went through a design pass so the same thing looks the same
everywhere: one control height, one chip, one empty state. Menus no longer let the
content beneath bleed through them. The `/` menu is grouped into sections by block
type instead of one long list. The Code editor's file panel is resizable and
remembers its width. Dashboard widgets no longer render on top of your app icons.
Browser pop-ups paint above the page rather than behind it.

One fix deserves naming properly. In Journal, if you opened a new day and started
typing immediately, the first words could be dropped — and once that happened,
that day's body stayed blank on every later visit, even though the word count
still showed the text. That is fixed.

The repair does not reach backwards, though, and we would rather say so than let
you find out. It stops new entries from being lost; it cannot recover text that was
already lost this way, because those words never reached the disk. If a day from
before 0.13.0 still shows an empty body, that content is gone.

macOS builds are signed with a Developer ID and notarized by Apple, so they open
without a Gatekeeper warning. Windows is currently unsigned, so you may see a
SmartScreen "unknown publisher" prompt, where the option you want is **More info**
then **Run anyway**. Existing installs update in-app from **Settings → Updates**.

It is still a beta, so keep backups of anything important. Your vault is a plain
folder you control completely.
