A user asked for resizable sticky notes — fair, because nothing on the
whiteboard was resizable. Now everything is: notes, shapes, images, frames.
Drag a corner, snap to neighbours, Shift for aspect, one Undo to take it back.

Also in this one: syntax highlighting finally respects the app theme (no more
light-on-dark code, no more permanently-dark blocks on light), Database number
columns line up with their totals, Calendar chips stop clipping, and a set of
small consistency fixes across Files, Contacts, Mailbox, and Notes.

macOS builds are signed with a Developer ID and notarized by Apple, so they open
without a Gatekeeper warning. Windows is currently unsigned (you may see a
SmartScreen "unknown publisher" prompt — choose **More info → Run anyway**).
Existing installs update in-app from **Settings → Updates**.

It's still a beta: keep backups of anything important. Your vault is a plain
folder you fully control.
